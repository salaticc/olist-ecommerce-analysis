# Данные

Сырые CSV не включены в репозиторий (большой размер, публичный датасет с фиксированным источником).

Скачать: [Kaggle — Brazilian E-Commerce Public Dataset by Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)

Для запуска ноутбука в эту папку нужны 4 файла:
- `olist_orders_dataset.csv`
- `olist_customers_dataset.csv`
- `olist_order_items_dataset.csv`
- `olist_order_reviews_dataset.csv`
